HOW TO PLAY — MORTAL FRETS

OBJECTIVE: Complete 10 questions per round with as few errors as possible. The timer runs throughout — leaderboard ranks by errors (fewer = better), then by time.

THE MODES:

  • Note ID: A dot appears on the fretboard — identify the note. The note sounds when it appears. Open strings (fret 0) are included.
  • Interval ID: Two dots appear. R = Root (red). The second dot (orange) is within ±3 frets and ±2 strings of the Root. Identify the interval. Both notes sound on correct answer.
  • Chord ID: A chord voicing appears — all notes within ±2 frets and ±2 strings of the Root, one note per string. Identify the chord type. All notes strum on correct answer.
  • Scale ID: A full scale pattern in a 5-fret box — R = Root (red). Identify the scale. The scale plays from the lowest Root up to the octave on correct answer. Choose a fixed box or 💀 KHAOS for a random box each question.

WRONG ANSWER: You stay on the same question and can keep retrying. The timer keeps running. After 2 wrong answers on the same question, the ☠ Mercy button lights up.

MERCY: Hold ☠ to reveal the answer on the fretboard. Release to hide it and retry. Mercy resets on each new question (requires 2 wrong answers to activate again).

VARIETY: In every round, the same note / interval / chord / scale type will not appear more than twice, and the exact same question will never repeat.

SCORING: 0 errors = FLAWLESS VICTORY · 1–2 = Excellent Fighter · 3–5 = Skilled Warrior · 6–10 = Fight Harder · 11–19 = Finish Him · 20+ = Fatality
