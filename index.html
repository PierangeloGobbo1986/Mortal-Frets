HOW TO PLAY — MORTAL FRETS

OBJECTIVE: Complete 10 questions per round with as few errors as possible. The timer runs throughout — leaderboard ranks by errors (fewer = better), then by time.

IDENTIFICATION MODES — a question appears on the fretboard, you press the correct button:

  • Note ID: A dot appears — identify the note. Sounds when it appears. Open strings (fret 0) included.
  • Interval ID: R = Root (red), second dot within ±3 frets/±2 strings. Identify the interval. Both notes sound on correct answer.
  • Chord ID: Chord voicing within ±2 frets/±2 strings of root, one note per string. Identify the chord type. All notes strum on correct answer.
  • Scale ID: Full scale in a 5-fret box, R = Root. Identify the scale. Scale plays from lowest Root up to the octave on correct answer.

CONSTRUCTION MODES — the target is shown (illuminated button), you build it on the fretboard by clicking, then press SUBMIT:

  • Note Construction: Place ALL occurrences of the target note on the fretboard. Wrong dots turn red; missing positions turn orange — click orange to confirm.
  • Interval Construction: R is pre-placed (red). Place the interval note anywhere on the fretboard at the correct pitch.
  • Chord Construction: One chord tone is pre-placed (amber). Place the remaining notes in any order — any string, any fret — to complete the chord. One note per string. Triads = 3 notes total, tetrads = 4.
  • Scale Construction: R is pre-placed in a 5-fret box. Fill all scale note positions inside the box. Wrong dots turn red; missing ones turn orange.

BOX SELECTION — Chord and Scale modes (both ID and Construction) let you work on a fixed 5-fret box or 💀 KHAOS for a random box each question.

WRONG ANSWER: You stay on the same question and can retry. Timer keeps running. After 2 wrong answers, the ☠ Mercy button lights up.

MERCY: Hold ☠ to reveal the full solution on the fretboard. Release to hide it and retry. Resets each new question.

VARIETY: Every type (note/interval/chord/scale) appears at most twice per round, and the exact same question never repeats.

SCORING: 0 errors = FLAWLESS VICTORY · 1–2 = Excellent Fighter · 3–5 = Skilled Warrior · 6–10 = Fight Harder · 11–19 = Finish Him · 20+ = Fatality
